# Indie Go Punk

A simple YouTube thumbnail generator for Indie Go Punk, a podcast
covering indie game developers, teams, and their games.

Work in stages: run experiments first, then combine the selected
results into a simple tool. Wait for the user's first experiment
before choosing a stack or implementing the app.
